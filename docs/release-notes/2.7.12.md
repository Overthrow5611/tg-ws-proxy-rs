# v2.7.12

"Check network" fixes from review:

- Detecting that the phone keeps the app off the network now asks Android
  (blocked network state, Data Saver) and also recognises the usual symptom of
  a per-app block — hostnames failing DNS while the direct IP times out.
  Before, such a block was reported as "no internet at all".
- Whitelist mode is reported whenever only ya.ru answers, whether Telegram's
  address drops packets or is cut during TLS.
- The three probes run in parallel, so a check on a dead network takes about
  a third of the time.

Also includes 2.7.11 (OpenWrt CI job runs upstream only).
