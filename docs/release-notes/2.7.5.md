# v2.7.5

## Android

- New minimal design: a status card with connections and traffic, mode chips,
  and collapsible launch settings and log.
- Appearance settings: system/light/dark theme, accent color (Material You
  from the wallpaper on Android 12+, or one of four fixed colors), and a pure
  black background for AMOLED screens.
- Both presets use `--ip-fail-cooldown 0`. In "Direct + Cloudflare", a single
  lost connect used to send every client to Cloudflare for the whole cooldown
  window; now each client tries direct first. In "Direct" it keeps the pool
  pre-connecting after a timeout instead of pausing it.

## Proxy

- `proxy::reset_cooldowns()` clears every failure cooldown; the Android shim
  calls it on each start, so a new run does not inherit the previous run's
  verdicts (it used to start with the `--dc-ip` already "in cooldown").
