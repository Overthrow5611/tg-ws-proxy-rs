# v2.7.8

First release published from the fork's GitHub Releases.

- New Russian README with install, setup, troubleshooting and bug-report instructions; issue templates.
- Releases are published automatically after a green CI run of a new version.

- A client whose pinned ladder has nothing it can dial (DC1 under
  `--pinned-upstream ws` with only `--dc-ip 2/4`) is now held for 3 s before
  the connection closes. It used to fail in microseconds, and Telegram
  reconnected at once: thousands of attempts and log lines a second, and a
  phone that never got to sleep. A ladder that dialled something and failed is not held.

Includes everything since 2.7.0: see the earlier notes in docs/release-notes/.
