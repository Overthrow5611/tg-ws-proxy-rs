# v2.7.7

- A client whose pinned ladder has nothing it can dial (DC1 under
  `--pinned-upstream ws` with only `--dc-ip 2/4`) is now held for 3 s before
  the connection closes. It used to fail in microseconds, and Telegram
  reconnected at once: thousands of attempts and log lines a second, and a
  phone that never got to sleep. Dials that already took 3 s are not held.
