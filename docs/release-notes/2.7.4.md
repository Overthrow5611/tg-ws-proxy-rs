# v2.7.4

Review fixes for 2.7.3.

- A `--check` run (with or without `--check-listener`) is never auto-restarted.
- Autostart after reboot/update is armed only once a run reaches its listener,
  and disarmed whenever the service gives up, so a failing config is not
  replayed at every boot.
- A retry whose worker exits during start schedules the next attempt instead
  of ending the retry loop.
- The Quick Settings tile and the status dot show "Restarting…", and the tile
  cancels the wait when tapped.
- The detailed-log switch understands `-q`, and no longer joins the lines of
  the arguments field.
- Re-opening the app while the proxy runs no longer hides the stats line until
  the next change.
