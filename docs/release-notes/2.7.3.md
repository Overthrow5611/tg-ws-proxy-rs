# v2.7.3

## Android

- Starts again after a reboot or an app update if it was left running.
- Restarts itself with backoff (2 s up to 60 s) when a run that was serving
  dies, instead of stopping. Runs that fail before listening still stop.
- The notification shows active Telegram connections and traffic.
- Russian interface.
- Presets ("Direct", "Direct + Cloudflare") and a "Detailed log" switch
  instead of editing the argument string by hand; Copy and Share for the log.

## Proxy

- Direct TCP connects that have not completed after 1 s start a second dial
  on a new source port and keep whichever handshake finishes first. This
  targets DPI that drops whole flows at the SYN; healthy connects (well under
  1 s) are unaffected.
- New `stats` module with process-wide counters (active clients, bytes of
  closed sessions) for embedders.
