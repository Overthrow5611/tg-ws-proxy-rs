# v2.7.6

## Android

- The CI release APK is now signed (same key as the debug build) and installs
  over it: about a third of the size, R8-optimised, not debuggable.
- New minimal icon with a themed-icon layer, and four launcher icons to pick
  from (blue, dark, light, green).
- "Check network": TLS handshakes to the direct endpoint and to Cloudflare,
  with a suggested mode. Only on request.
- Settings dialog: appearance, app icon, export/import of the settings (JSON
  via the file picker; contains the secret), and an on-demand update check
  against the fork on GitHub.
- The GitHub button opens the fork.

## Tests

- Instrumentation tests for the restart logic (a run that dies after
  listening comes back; Stop is final) and for the preset, `--quiet` and
  version-compare helpers.
- Integration tests for the staggered direct dial (a refusal returns before
  the second dial; a listener is reached).
