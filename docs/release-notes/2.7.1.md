# v2.7.1

Fork build (Overthrow5611/tg-ws-proxy-rs) for phones on throttled networks.

## Android

- The generated `--secret` is kept across restarts, so the link saved in
  Telegram stays valid after Stop/Start or a system restart of the service.
- Asks once to be excluded from battery optimisation. The proxy holds no
  wakelock, so this costs no battery; it matters on vendor ROMs that kill
  optimised apps with the screen off.
- Default arguments use direct WebSocket only (`--pinned-upstream ws`,
  `--ws-connect-timeout 3`, `--pool-size 1`). Where the community Cloudflare
  domains and raw TCP are blocked, falling back to them only kept a failed
  client waiting.
- Debug builds are signed with a committed key, so each CI build installs over
  the previous one.

## Proxy

- Upstream sockets get `TCP_USER_TIMEOUT` (20 s, Linux and Android). Throttling
  DPI tends to blackhole a flow rather than reset it. The timer only runs while
  data the proxy sent is unacknowledged, so a download-only stall is caught once
  Telegram sends its next request, ack or ping, not instantly. No extra packets
  are sent on idle sockets.
