# v2.7.10

- "Check network" now says *why* a path fails: no answer (packets dropped),
  blocked on the phone (per-app data restriction), no route, refused, DNS, or
  cut during TLS (DPI on the SNI). It also probes ya.ru, so it can tell a
  carrier whitelist (only Russian services answer) from the phone blocking
  the app, and says which one it is.
- Release workflow: a failed releases lookup no longer loses a release;
  drafts and prereleases are ignored when picking "Latest".
