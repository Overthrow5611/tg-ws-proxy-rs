# TG WS Proxy для Android (форк)

Приложение для Android, которое возвращает Telegram там, где его режут. Оно поднимает на телефоне
локальный MTProto-прокси и прячет трафик Telegram в WebSocket-соединения к `web.telegram.org`,
то есть в то же, чем пользуется браузерная версия Telegram.

Это форк [valnesfjord/tg-ws-proxy-rs](https://github.com/valnesfjord/tg-ws-proxy-rs) (Rust-порт
[Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)), доработанный под телефон:
стабильность в фоне, экономия батареи и простой интерфейс.

- 🔋 **Не VPN.** Через приложение идёт только Telegram, фоновой нагрузки и wakelock'ов нет.
- 🔁 **Не отваливается.** Само поднимается после сбоя, перезагрузки и обновления, а зависшие
  соединения закрывает.
- 🧼 **Без трекеров.** Нет аналитики, рекламы и Google Play Services: только AndroidX и
  Jetpack Compose.
- 🎨 **Минималистичный интерфейс** на русском: светлая, тёмная и AMOLED-тема, цвета Material You
  и 4 иконки на выбор.

## Установка

1. Откройте [Releases](../../releases/latest) и скачайте **`tg-ws-proxy-<версия>-arm64-v8a.apk`**.
   Он подходит почти всем телефонам последних лет. Если не уверены, берите `universal`.
2. Откройте файл на телефоне и разрешите установку из этого источника.
   Если Google Play Защита предложит проверку, нажмите «Подробнее» → «Установить без проверки».
   Окно появляется у любого приложения не из Play Маркета.
3. Обновления ставятся поверх, настройки сохраняются.

Требуется Android 8.0 или новее.

## Первый запуск

1. Откройте приложение и разрешите уведомления. На вопрос про батарею нажмите **«Разрешить»**:
   прокси не держит телефон проснувшимся, исключение только не даёт системе его убить.
2. Нажмите **«Старт»**. Приложение откроет Telegram со ссылкой на прокси, нажмите
   **«Подключить прокси»**. Ссылка постоянная, добавить её нужно один раз.
3. Нажмите **«Проверить сеть»**: приложение покажет, какие пути до Telegram живы, и подскажет режим.

### Настройки телефона (важно)

Многие прошивки убивают фоновые приложения даже с уведомлением. Тогда Telegram периодически
теряет соединение.

| Прошивка | Что включить |
|---|---|
| Honor / Huawei (MagicOS, EMUI) | Настройки → Батарея → Запуск приложений → TG WS Proxy → выключить «Управлять автоматически», включить все три переключателя |
| Xiaomi / Redmi / POCO (HyperOS, MIUI) | О приложении → Автозапуск ✔; Контроль активности → «Нет ограничений» |
| Samsung (One UI) | Батарея → «Без ограничений»; убрать приложение из «Спящих» |
| Любая | Закрепить приложение замочком в списке недавних |

Подробнее по каждой модели: [dontkillmyapp.com](https://dontkillmyapp.com).

## Режимы

- **Прямое** (по умолчанию). WebSocket напрямую к `149.154.167.220`. Самый быстрый вариант,
  работает в большинстве сетей.
- **Прямое + Cloudflare.** Если прямое соединение не прошло, пробует общие Cloudflare-домены
  сообщества. Нужен только там, где прямой путь заблокирован.

Свои аргументы командной строки можно задать в разделе «Параметры запуска». Все флаги описаны
в [документации оригинального проекта](docs/README-upstream.md).

## Что-то не работает

1. Включите **«Подробный лог»** в «Параметрах запуска», нажмите Стоп → Старт и воспроизведите проблему.
2. Нажмите **«Поделиться»** у лога или «Копировать».
3. [Создайте issue](../../issues/new/choose): приложите лог, модель телефона, версию Android
   и опишите, когда пропадает связь (после сна, при смене сети, просто так).

Частые вопросы:

- **В логе много `CF WS … timed out`.** Выбран режим «Прямое + Cloudflare», а Cloudflare в
  вашей сети заблокирован. Переключитесь на «Прямое».
- **`DC1 every pinned upstream failed`.** В режиме «Прямое» путь есть только к DC2 и DC4, где
  живёт большинство аккаунтов и медиа. Запросы к DC1, DC3 и DC5 прокси отклоняет с паузой в 3 с,
  чтобы Telegram не долбился. Если у вас не грузятся отдельные каналы или картинки, попробуйте
  «Прямое + Cloudflare» (если Cloudflare в вашей сети доступен, это покажет «Проверить сеть»).
- **Иконка пропала с рабочего стола после обновления или смены иконки.** Верните её из меню
  приложений. Так ведут себя лаунчеры при смене иконки.

## Сборка

Каждый пуш в `main` собирает и тестирует GitHub Actions (Rust-тесты, сборка APK, тесты на
эмуляторах Android 8 и 16). Сборка с новой версией автоматически публикуется в Releases.
Собрать локально: [docs/Android.md](docs/Android.md).
